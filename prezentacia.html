Backend

Bezpečnosť & Backend

🔑 Ochrana API kľúčov

OpenAI API kľúč je uložený výhradne vo Firebase Secret Manager. iOS aplikácia s ním nikdy nepríde do kontaktu, komunikuje iba s Cloud Function.

🛡️ Firestore bezpečnostné pravidlá

Každý používateľ môže čítať a písať iba vlastné dokumenty. Pravidlo: request.auth.uid == resource.data.userId

⏱️ Timeout & Rate Limiting

Cloud Function má nastavený timeout 5 minút. Klientská strana používa retry logiku s exponenciálnym čakaním.

☁️ Cloud Function (Node.js)

GPT-4o-mini vygeneruje plán, uloží ho do Firestore a vráti výsledok iOS aplikácii ako štruktúrovaný JSON.
